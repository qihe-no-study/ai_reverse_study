# 维普期刊 — RS6 瑞数反爬 逆向文档

## 概况

| 项目 | 内容 |
|------|------|
| 目标 | `https://qikan.cqvip.com/Qikan/Journal/JournalGuid?from=index` |
| 防护 | 瑞数 RS6（412 JS 挑战 + $_ts VM + S+T Cookie 对） |
| 方案 | 路径 B 环境伪装（sdenv + jsdom） |
| 复杂度 | L3: 虚拟机保护 + 环境依赖 |

## 架构

```
Python(fetch_page.py) → subprocess → Node.js(sdenv_rs6.js) → sdenv
    ↓                                                              ↓
requests.get(Cookie) ← stdout ← Cookie ← 412挑战 → VM执行 → S+T Cookie对
    ↓
HTTP 200 → data/journal_guid.html
```

## 目录结构

```
qikan/reverse_code/
├── fetch/fetch_page.py        # Python 调度入口
├── code/sdenv_rs6.js          # Node.js sdenv 核心
├── prompt/                    # 任务规格书
└── data/                      # 产出 (gitignore)
```

## 关键文件

| 文件 | 用途 |
|------|------|
