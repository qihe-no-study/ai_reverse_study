1. 🎯 起点：Python调度中心

fetch_page.py是统一入口。main()→get_cookies()→subprocess调用Node.js→fetch_page()带Cookie请求→保存结果。理解这个调用链就理解了整个数据流。

2. 🔐 核心难点：RS6 412挑战→Cookie生成

RS6（瑞数6）首次请求必然返回412+$_ts JS挑战。226KB VM字节码需要完整浏览器环境（document.all、canvas.toDataURL等）才能执行。sdenv通过jsdom+环境补丁+VM执行自动完成：412→Cookie→200。

3. 🔧 sdenv集成方案

sdenv=jsdom模拟+环境补丁+VM执行的三合一方案。jsdomFromUrl自动处理完整412挑战流程。需要Node.js v20.19.5+和VS2022 Build Tools编译C++模块（canvas等）。这是路径B（环境伪装）的典型应用。

4. 📊 数据流：Python→Node.js→Python闭环

Python subprocess启动Node.js→sdenv处理412生成Cookie→stdout输出→Python解析Cookie→requests.get带Cookie请求→200真实页面→保存data/。完整闭环，全程无浏览器。
