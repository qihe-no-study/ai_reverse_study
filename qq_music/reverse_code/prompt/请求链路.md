## 加密机制

| 项目 | 内容 |
|---|---|
| 算法 | AES-128-GCM |
| 密钥 | `bd305f10d0ff74b6ef54dab835b5e1cf` (16字节 hex) |
| IV | 每次随机 12 字节 |
| 流程 | 明文JSON -> TextEncoder.encode -> SubtleCrypto.encrypt(AES-GCM) -> base64 编码 -> POST body |
| 响应 | ArrayBuffer -> SubtleCrypto.decrypt(AES-GCM) -> TextDecoder.decode -> JSON |

## sign 生成

| 项目 | 内容 |
|---|---|
| 格式 | `zzc` + hex 字符串 + 字母 |
| 输入 | 加密前的明文 JSON 字符串 |
| 算法 | JSVMP 保护的 SHA-1 变种 |
| 位置 | vendor.chunk.js offset:38639 `getSecuritySign` |
| 初始常量 | `[1732584193, 4023233417, 2562383102, 3285377520]` (SHA-1) |
