# QQ音乐 — 逆向全链路分析

## 1. 目标

| 项 | 内容 |
|----|------|
| URL | `https://y.qq.com/n/ryqq_v2/songDetail/0004BoFH1kpYFC` |
| 歌曲 | 爱你 (青春离别版) - 高睿 / Song MID: 0004BoFH1kpYFC |
| 目的 | 获取歌曲 MP3、歌词、评论数据 |

## 2. 请求链路总览

```
浏览器访问歌曲页
  → SSR 渲染页面（含 __INITIAL_DATA__）
  → JS 加载 vendor.chunk.js（含 sign 模块）
  → POST u6.y.qq.com/cgi-bin/musics.fcg?sign={sign}
     - 歌词: music.musichallSong.PlayLyricInfo.GetPlayLyricInfo
     - 评论: music.globalComment.CommentRead.GetNewCommentList
     - 歌曲URL: vkey.GetVkeyServer.CgiGetVkey
  → 响应 JSON → 渲染
```

## 3. 防护机制分析

### 3.1 第一层：sign 签名

**发现过程：**

1. DOMTRACE 捕获到 `musics.fcg` 的 POST 请求，Query 参数含 `sign=zzc...` 
2. 在 vendor.chunk.js 中搜索 `sign`，定位到 `getSecuritySign` 函数（offset:38639）
3. 该函数被 JSVMP（JS 虚拟机保护）加密——源码被编译为自定义字节码，由内置解释器执行

**算法还原：**

```javascript
// JSVMP 解释器特征
- 初始常量: [1732584193, 4023233417, 2562383102, 3285377520]  // SHA-1 IV
- 内部函数: __sign_hash_20200305  // MD5 变种
- 输入: 明文 JSON body 字符串（注意：是加密前的明文！）
- 输出: "zzb" + 40 字符 hex/alpha（Node.js 环境前缀 zzb，浏览器 zzc，服务端均接受）
```

### 3.2 第二层：AES-GCM 加密通道（可选）

**发现过程：**

1. 浏览器请求的 Query 参数含 `encoding=ag-1`
2. 抓包发现 Body 是 base64 密文而非明文 JSON
3. DOMTRACE 记录到 `SubtleCrypto.encrypt` 调用

**还原结果：**

| 参数 | 值 |
|------|-----|
| 算法 | AES-128-GCM |
| 密钥 | `bd305f10d0ff74b6ef54dab835b5e1cf`（16 字节 hex，硬编码在 JS 中） |
| IV | 每次随机 12 字节 |
| 请求 | 明文 JSON → TextEncoder → AES-GCM encrypt → base64 → POST body |
| 响应 | **不是标准 AES-GCM！** 是 JSVMP 自定义 `__cgiDecrypt` 同步密码 |

**关键踩坑：** 响应解密不是 AES-GCM，而是另一套 JSVMP 保护的算法（crypto.js + jsvmp2_raw.js）。这一度导致解密失败，直到对比 DOMTRACE 的 `SubtleCrypto.decrypt` 调用链与 JSVMP 字节码才确认。

### 3.3 环境依赖

JSVMP 运行时检测以下浏览器 API，缺失则执行失败：

| 属性 | 补丁值 | 说明 |
|------|--------|------|
| `navigator.userAgent` | Chrome/147 UA | 必须有 |
| `location.host` | `y.qq.com` | 域名校验 |
| `window` | 自引用 | 循环引用自身 |

**Node.js v24 兼容性踩坑：** Node.js v24+ 内置了全局 `navigator` 对象，且不可覆盖。解决方案：在 sign.js 中使用独立的 `n` 对象替代 `globalThis`，所有 VM 代码在 `n` 的作用域内执行。

## 4. API 接口

### 4.1 统一入口

```
POST https://u6.y.qq.com/cgi-bin/musics.fcg?_={timestamp}&sign={sign}
Content-Type: application/x-www-form-urlencoded
Body: 紧凑 JSON (separators=(",",":"))
```

### 4.2 公共参数 comm

```json
{
  "cv": 4747474, "ct": 24, "format": "json",
  "platform": "yqq.json", "uin": 854594834,
  "g_tk": "<hash5381(qqmusic_key)>",
  "g_tk_new_20200303": "<hash5381(qqmusic_key)>"
}
```

### 4.3 业务接口

| 模块.方法 | 用途 | 状态 |
|-----------|------|------|
| `music.musichallSong.PlayLyricInfo.GetPlayLyricInfo` | 歌词（base64 LRC） | 稳定 |
| `music.globalComment.CommentRead.GetNewCommentList` | 评论（游标翻页） | 稳定 |
| `vkey.GetVkeyServer.CgiGetVkey` | 歌曲播放 URL | 稳定 |
| `music.vkey.GetEVkey.GetUrl` | 歌曲 URL（新版） | **不可用** |
| `QQConnectLogin.LoginServer.QQLogin` | Cookie 刷新 | 稳定 |

### 4.4 关键发现：双版本 Vkey API

这是我们花时间最多的问题之一：

- `music.vkey.GetEVkey.GetUrl`：浏览器走加密通道时正常，明文通道下持续返回 `104009 invalidq`，**即使 cookie 完全有效**
- `vkey.GetVkeyServer.CgiGetVkey`：经典接口，需要 `filename` 参数，稳定返回

如果没有 DOMTRACE 对照浏览器实际使用的接口，仅靠猜测很难发现这个差异。

## 5. 环境补丁完整清单

在 sign.js 中构造独立作用域对象 `n`：

```javascript
var n = {
  Object, Array, String, Number, Boolean, RegExp, Math, Date, JSON,
  parseInt, parseFloat, isNaN, isFinite,
  encodeURIComponent, decodeURIComponent, unescape, escape,
  undefined, NaN, Infinity, Function, Error, TypeError,
  window: {},           // 自引用
  navigator: {
    userAgent: "Mozilla/5.0 ... Chrome/147 ..."
  },
  location: {
    host: "y.qq.com",
    hostname: "y.qq.com",
    href: "https://y.qq.com/",
    protocol: "https:"
  },
  document: { cookie: "" },
  self: null
};
n.self = n;
n.window = n;
```

## 6. Cookie 刷新机制

- `musickey` 每 3 天过期（`keyExpiresIn: 259200`）
- `access_token` 有效期约 60 天（`psrf_access_token_expiresAt`）
- 60 天内可通过 `QQLogin` 接口无限次刷新 musickey，无需浏览器登录
- `g_tk = hash5381(qqmusic_key)`，更换 musickey 后必须重新计算

## 7. 最终方案

```
Python(main.py)                    Node.js
     │                                │
     ├─ subprocess ──────────────→ sign_server.js
     │                                ├─ require('./sign.js')
     │                                ├─ getSecuritySign(body)
     │                                └─ stdout → sign
     │                                │
     ├─ requests.post ───────────→ musics.fcg?sign={sign}
     │   Body: 明文 JSON               │
     │                                │
     ├─ 歌词: base64.decode → .lrc
     ├─ 评论: LastCommentSeqNo 翻页
     └─ 歌曲: CgiGetVkey → purl+sip → stream download → .mp3
```

4. 观察输出：歌词 → 评论翻页 → 歌曲下载
