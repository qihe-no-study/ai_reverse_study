# QQ音乐 — JSVMP 签名破解 逆向文档

## 概况

| 项目 | 内容 |
|------|------|
| 目标 | `https://y.qq.com/n/ryqq_v2/songDetail/0004BoFH1kpYFC` |
| 防护 | JSVMP 虚拟机保护（MD5 变种签名）+ AES-GCM 加密通道 |
| 方案 | 路径 B 环境伪装（独立作用域 + 环境补丁） |
| 复杂度 | L3: 多层壳 + 环境依赖 |

## 架构

```
Python(main.py) → subprocess → Node.js(sign_server.js) → sign.js(JSVMP) → sign
                                                        ↓
Python ← requests ← musics.fcg?sign={sign} ← POST ← 明文JSON body
```

## 目录结构

```
qq_music/reverse_code/
├── fetch/main.py              # Python 调度入口
├── code/sign.js               # JSVMP 签名模块
├── code/sign_server.js        # Node.js CLI 桥接
├── code/crypto.js             # AES-GCM 加密通道
├── code/jsvmp2_raw.js         # 第二段 JSVMP 字节码
├── prompt/                    # 技术报告 + 参考文档
└── data/                      # 产出 (gitignore)
```

## 关键文件

| 文件 | 用途 |
|------|------|
| [main.py](reverse_code/fetch/main.py) | Python 入口：调度签名生成 + API 请求 |
| [sign.js](reverse_code/code/sign.js) | JSVMP 签名模块（含环境补丁） |
| [sign_server.js](reverse_code/code/sign_server.js) | Node.js CLI：接收 JSON → 返回 sign |
| [crypto.js](reverse_code/code/crypto.js) | AES-GCM 加密通道（备用） |
| [REPORT.md](reverse_code/prompt/REPORT.md) | 完整技术报告 |
| [SKILLS.md](reverse_code/prompt/SKILLS.md) | 快速参考手册 |
